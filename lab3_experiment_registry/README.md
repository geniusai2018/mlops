# lab3_experiment_registry · 어느 것이 나은지 말할 수 있게

> MLOps · 블록 4(실험 관리) · 제한시간 **25분**
> 앞 실습(lab2)에서 **같은 것이 두 번 나오게** 했습니다. 이번에는 **서로 다른 것을 여러 번 만들어 놓고 하나를 고릅니다.**

## 미션

설정을 바꿔 세 번 학습하고, 각각을 **기록**하고, 비교표를 보고 **하나를 골라 등록·승격**합니다.
`검증/check-registry.py` 8가지를 통과시키십시오.

기억해 둘 문장 하나입니다 — **비교할 수 없는 실험은 하지 않은 것과 같습니다.**

## 약속한 것

```
python experiments.py
  → mlflow.db              실험 기록 (설정 · 지표 · 모델이 한 곳에)
  → 등록 모델 dropout-risk  고른 것에 붙인 이름
  → 별칭 production        그 이름 중 「지금 쓰는 것」을 가리키는 손가락
  → 실험비교.md            사람이 읽는 비교표와 선택 이유 (손으로 씁니다)
```

검증 스크립트(교재: 점검기)는 이 약속만 봅니다. 어떤 설정을 고르셨는지는 묻지 않습니다.

## 세 가지 설정 — 이미 적어 두었습니다

| 설정 | 쓴 특성(교재: 특징) | 클래스 가중치 | 앞 설정에서 바뀐 점 |
|---|---|---|---|
| A_기본 | 6개 전부 | 없음 | 기준점 |
| B_가중치 | 6개 전부 | balanced | A에서 **가중치만** |
| C_출석만 | 출석률·지각 2개 | balanced | B에서 **특성만** 줄임 |

**한 번에 한 가지만 바꿨습니다.** 두 가지를 같이 바꾸면 좋아졌을 때 무엇 덕분인지 말할 수 없습니다.

## 단계

1. **(2분)** 지금 상태를 봅니다. **2개 통과 · 6개 실패**로 시작합니다.
   ```
   python experiments.py
   python ../검증/check-registry.py .
   ```
   돌아가기는 합니다. 숫자도 나옵니다. 그런데 **창을 닫으면 사라집니다.**
2. **(8분)** TODO 1·2 — 설정과 지표를 기록에 남깁니다.
   검증 스크립트가 보는 것은 **설정이 서로 다른가**입니다. 세 기록의 설정이 똑같으면 비교가 아닙니다.
3. **(6분)** TODO 3 — 모델 자체를 남기고 `dropout-risk` 라는 이름에 등록합니다.
   기록만 있고 물건이 없으면 꺼내 쓸 수 없습니다.
4. **(5분)** TODO 4 — 고른 버전에 `production` 별칭을 겁니다.
5. **(4분)** TODO 5 — `실험비교.md` 를 손으로 씁니다. 표 + **왜 그것을 골랐는지** + **다시 보게 될 조건(하한)**.
   강의 기준값은 재현율 0.60 · 정밀도 0.40 — 2일차 실습 6의 승격 게이트(교재: 관문)가 이 값을 씁니다.

## 고르는 기준을 먼저 정하십시오

시작 코드는 **정확도**로 고르게 되어 있습니다. 그대로 두어도 검증 스크립트는 통과합니다.
그런데 이 모델의 쓰임을 생각해 보십시오.

| 무엇을 놓치나 | 그러면 무슨 일이 | 값 |
|---|---|---|
| 이탈할 훈련생을 못 찾았다 | 그대로 이탈한다 | 비싸다 |
| 안 나갈 훈련생이 잘못 걸렸다 | 상담을 한 번 더 받는다 | 싸다 |

이탈자가 전체의 3할입니다. 그러니 **전부 「안 나간다」고만 답해도 정확도는 0.7**이 됩니다.
**정확도는 이 문제에서 고르는 기준이 될 수 없습니다.** 무엇으로 보시겠습니까.

## 심화 (먼저 끝난 분)

`심화/README.md` — 그 차이는 우연인가 — 시드(교재: 씨앗값) 스무 개로 다시 재고, 자르는 선을 비용으로 정한다. 15분 안팎이고 검증 스크립트가 따로 있습니다.

## 막혔을 때

| 증상 | 이렇게 |
|---|---|
| E3이 실패한다 | 세 기록의 설정이 똑같습니다. 설정마다 **다른 값**을 남기셨습니까 |
| E4가 실패한다 | `registered_model_name` 을 빠뜨렸거나 이름이 다릅니다. `dropout-risk` |
| E6이 실패한다 | 별칭은 **버전 번호**에 겁니다. run_id 가 아닙니다 |
| E7이 실패한다 | 표만 있고 이유가 없습니다. 「왜 이것을 골랐는가」를 적으십시오 |
| `mlflow` 가 없다 | `pip install --user mlflow`. 막히면 아래 대체 경로 |
| 화면에 경고가 잔뜩 뜬다 | 기록은 정상입니다. 검증 스크립트 결과만 보십시오 |

## 대체 경로 (설치가 막힐 때)

**기록의 본질은 도구가 아니라 「설정·지표·산출물을 한 자리에 남기는 것」입니다.**
MLflow 가 안 되면 `실험기록.jsonl` 에 한 줄씩 남기는 것으로 대신합니다 — 설정·지표·모델
파일 경로를 한 줄로. 이 경우 E0·E4·E5·E6은 건너뛰고 **E3·E7** 에 집중하십시오.
개념은 그대로이고, 도구는 나중에 바꿔 끼울 수 있습니다.
