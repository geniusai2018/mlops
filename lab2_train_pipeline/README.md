# lab2_train_pipeline · 학습을 고정한다

> MLOps · 블록 3(모델 학습 파이프라인) · 제한시간 **25분**
> **이 과정에서 가장 중요한 실습입니다.** 여기가 안 되면 뒤의 네 실습이 모두 흔들립니다.

## 미션

`train.py` 를 고쳐 **두 번 돌리면 같은 결과가 나오게** 만듭니다.
`검증/check-repro.py` 8가지를 통과시키십시오.

> 재현되지 않는 학습은 실험 관리도, 배포도, 롤백도 의미가 없어집니다.
> 「지난주 그 모델」을 다시 만들 수 없으면 **무엇이 좋아졌는지도 말할 수 없습니다.**

## 약속한 것

```
python train.py 출력폴더
  → 출력폴더/predictions.csv   검증셋 예측
  → 출력폴더/RUN.json          씨앗값 · 설정 · 데이터 버전 · 성능 지표
```

검증 스크립트(교재: 점검기)는 이 약속만 봅니다. **모델을 어떻게 만드는지는 묻지 않습니다.**

## 단계

1. **(2분)** 지금 상태를 봅니다. **4개 통과 · 4개 실패**로 시작합니다.
   ```
   python ../검증/check-repro.py .
   ```
2. **(10분)** TODO 1·2 — 매번 달라지는 자리를 찾아 고정합니다.
   한 곳만 고쳐도 R3이 통과할 수 있습니다. 그래도 멈추지 마십시오 — 지금 모델에서는 결과를 바꾸지 않지만
   **모델을 바꾸는 순간 결과를 흔드는 자리**가 더 있습니다. 무작위를 쓸 수 있는 곳은 모두 고정합니다.
3. **(8분)** TODO 3 — `RUN.json` 에 남길 것을 채웁니다.
   기준은 하나입니다 — **「이 모델은 무엇으로 배웠습니까」에 이것만 보고 답할 수 있는가.**
4. **(5분)** 다시 점검하고, 통과하면 **한 번 더 돌려** 같은 값이 나오는지 눈으로 확인합니다.

## 완료 기준

- [ ] 점검 **8개 전부** 통과
- [ ] **R3(예측이 같다)** 를 통과했다 — 이것 하나가 나머지보다 중요합니다
- [ ] 「어디를 고정했습니까」를 한 문장으로 말할 수 있다

## 무엇이 매번 달라지나

| 흔한 자리 | 왜 |
|---|---|
| 데이터를 나누는 순간 | 섞는 방식이 매번 다르면 학습셋 자체가 달라진다 |
| 모델 안의 무작위 | 알고리즘에 따라 초기값·표본 추출이 무작위다 |
| 파일을 읽는 순서 | 폴더를 훑어 얻은 목록은 순서가 보장되지 않는다 |
| 시간·난수 | 지금 시각이나 시드(교재: 씨앗값) 없는 난수를 쓰면 당연히 달라진다 |

## 심화 (먼저 끝난 분)

`심화/README.md` — 빈 값 채우기를 모델 안으로 — 학습할 때 한 손질이 모델과 함께 다니게 한다. 15분 안팎이고 검증 스크립트가 따로 있습니다.

## 막혔을 때

| 증상 | 이렇게 |
|---|---|
| R3만 계속 실패한다 | 데이터를 **나누는 순간**을 먼저 보십시오 |
| R3은 통과했는데 다 고쳤는지 모르겠다 | 모델 쪽 `random_state` 와 **읽는 파일의 순서**도 고정했는지 보십시오 |
| R6이 실패한다 | `seed` 와 `params` 라는 이름으로 넣으셨습니까 |
| R5가 실패한다 | 데이터의 **해시(교재: 지문)**가 필요합니다. 파일 내용을 해시로 |
| 통과했는데 값이 이상하다 | 재현성과 성능은 다른 문제입니다. 지금은 **재현**만 봅니다 |

## 대체 경로

**네트워크가 필요 없습니다.** 검증 스크립트가 임시 폴더에서 두 번 돌리므로 작업 폴더가 지저분해지지 않습니다.
