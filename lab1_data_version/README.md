# lab1_data_version · 데이터에 버전을 붙인다

> MLOps · 블록 2(데이터 관리와 버저닝) · 제한시간 **25분**

## 미션

학습에 쓸 데이터에 **버전을 붙이고**, 무엇이 들어 있는지 **기록**합니다.
`검증/check-data.py` 6가지를 통과시키십시오.

> 이 실습이 답하려는 질문은 하나입니다 — **「이 모델은 무엇으로 배웠습니까」**
> 석 달 뒤에 이 질문을 받았을 때 답할 수 있게 만드는 일입니다.

## 입력물

| 파일 | 무엇 |
|---|---|
| `../공용데이터/trainees_2025-*.csv` | 대면 기수 두 개. **원본이므로 고치지 않습니다** |
| `시작코드/버전만들기.py` | TODO 세 곳 |
| `검증/check-data.py` | 점검 6가지 |

## 단계

1. **(3분)** 원본을 열어 봅니다. 몇 행이고, 중복이 있고, 결측이 있습니까. (`lab1_data_version` 폴더에서 — `시작코드` 안이면 경로를 `../../공용데이터/…` 로)
   ```
   python -c "import pandas as pd; d=pd.read_csv('../공용데이터/trainees_2025-2.csv'); print(len(d), d.duplicated().sum(), d.isna().sum().sum())"
   ```
2. **(7분)** TODO 1 — MANIFEST 를 채웁니다. 해시·행수·중복·결측.
3. **(7분)** TODO 2·3 — v1(원본 그대로)과 v2(손본 것)를 저장합니다.
   **중복과 결측을 어떻게 할지는 여러분이 정하십시오.** 정답은 없습니다.
4. **(8분)** `데이터카드.md` 를 씁니다. **무엇을 왜 했는지**가 핵심입니다.

## 완료 기준

- [ ] 점검 **6개 전부** 통과
- [ ] v1을 **손대지 않고** 남겼다
- [ ] 데이터카드에 **v1 → v2 에서 내린 판단과 그 이유**가 적혀 있다

## 왜 원본(v1)을 남깁니까

손본 데이터만 있으면 **「원래 무엇이 있었는지」를 되짚을 수 없습니다.**
「중복을 왜 지웠습니까」를 나중에 물었을 때, v1이 없으면 답할 방법이 없습니다.

## 심화 (먼저 끝난 분)

`심화/README.md` — 데이터 계약과 누수 — 약속을 코드로 적고, 넣으면 안 되는 칸을 가려낸다. 15분 안팎이고 검증 스크립트(교재: 점검기)가 따로 있습니다.

## 막혔을 때

| 증상 | 이렇게 |
|---|---|
| D3(해시 불일치)가 계속 실패 | 파일을 저장한 **뒤에** 해시를 찍어야 합니다. 순서를 보십시오 |
| D5(버전끼리 다르다)가 실패 | v1과 v2가 같은 내용입니다. v2에서 실제로 무언가를 바꾸셨습니까 |
| D6이 실패 | 데이터카드가 너무 짧습니다. 판단과 이유를 적으십시오 |
| 중복을 어떻게 할지 모르겠다 | **지우는 것이 흔한 선택**입니다. 다만 왜 지웠는지를 적으십시오 |
