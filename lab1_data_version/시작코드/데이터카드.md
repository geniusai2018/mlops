# 데이터카드 — 중도탈락 위험 예측 학습 데이터

## 무엇을 담고 있나
2025-1 · 2025-2 두 기수(대면)의 훈련생 기록. 모두 가상 데이터다.
특징 6개(최근 4주 출석률·지각·과제 제출률·과제 지연률·상담 횟수·관련 경력)와 답(dropped).

## 버전
- v1: 받은 그대로. 632행 · 중복 12 · 결측 25. 손대지 않았다.
- v2: 중복 12행을 지우고, 결측 25칸을 열마다 중앙값으로 채웠다. 620행 · 중복 0 · 결측 0.

## v1 → v2 판단과 이유
중복은 같은 사람이 두 번 들어간 것으로 보고 지웠다. 학습이 그 사람 쪽으로 치우치지 않게.
결측은 행을 지우면 사람이 줄어들어 중앙값으로 채웠다. 채운 값은 실제 값이 아니다.
