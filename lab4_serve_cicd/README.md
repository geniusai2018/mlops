# lab4_serve_cicd · 약속을 지키는 문을 낸다

> MLOps · 블록 7(모델 서빙·배포 자동화) · 제한시간 **30분**
> lab3에서 **고른 모델**이 생겼습니다. 이제 그것을 **밖에서 부를 수 있게** 만듭니다.

## 미션

`serve.py` 를 고쳐 추론 API가 **약속을 지키게** 만듭니다.
`검증/contract-test.py` 10가지를 통과시키십시오.

기억해 둘 문장 하나입니다 — **바깥과의 약속은 고정하고, 안쪽 모델은 갈아 끼웁니다.**

## 준비 (한 번만)

```
python 준비.py
```

`mlflow.db` 와 `mlruns/` 가 **돌린 폴더**에 생깁니다. `serve.py` 옆에서 돌리십시오.

lab3에서 손으로 하신 것을 한 번에 해 줍니다. 2개를 등록하고 나중 것에 `production` 을 겁니다.

| 버전 | 무엇 | 별칭 |
|---|---|---|
| v1 | 출석·지각 **둘만** 쓰는 옛 모델 | — |
| v2 | 특성(교재: 특징) **여섯 개**를 다 쓰는 모델 | `@production` |

**lab3을 못 끝내셨어도 이 실습은 진행됩니다.**

## 약속한 것

```
GET  /health    살아 있는가                200 · {"status": ...}
GET  /model     지금 누가 답하고 있는가      이름 · 버전 · 별칭
POST /predict   위험도 한 건               risk(0~1) · label(0|1) · version
                                          잘못된 입력에는 4xx — 500은 실패
```

검증 스크립트(교재: 점검기)는 이 약속만 봅니다. **모델이 좋은지는 묻지 않습니다.**

## 지금 무엇이 잘못되어 있나

시작 코드는 **돌아갑니다.** 답도 줍니다. 그런데 쓸 수가 없습니다.

| 지금 상태 | 그래서 무슨 일이 |
|---|---|
| 버전 번호가 코드에 박혀 있다 | 모델을 갈아 끼울 때마다 이 파일을 고쳐야 한다 |
| `/model` 이 없다 | 장애가 났을 때 **무엇이 답하고 있었는지** 알 방법이 없다 |
| 받은 것을 그대로 믿는다 | 출석률 1.5 를 받아 그럴듯한 답을 내놓는다 |
| 응답에 버전(교재: 답에 버전)이 없다 | 석 달 뒤 「이 답 누가 줬습니까」에 대답할 수 없다 |

## 단계

1. **(3분)** 지금 상태를 봅니다. **5개 통과 · 5개 실패**로 시작합니다.
   ```
   python 준비.py
   python ../검증/contract-test.py .
   ```
2. **(7분)** TODO 1 — 모델을 **별칭**으로 부릅니다. 버전 번호를 지웁니다.
   그 버전이 쓰는 특성 목록도 같이 가져옵니다 (버전 태그 `features`).
3. **(6분)** TODO 2 — `GET /model` 을 엽니다.
4. **(8분)** TODO 3 — 입력을 검증합니다. **여섯 항목을 전부 받습니다.**
   지금 모델이 그중 둘만 쓰더라도 바깥과의 약속은 고정입니다.
5. **(3분)** TODO 4 — 응답에 버전을 담습니다.
6. **(3분)** 점검하고, 브라우저에서 눈으로 확인합니다.
   ```
   uvicorn serve:app --reload --port 8000
   ```
   → `http://127.0.0.1:8000/docs` 에서 직접 눌러 볼 수 있습니다.
7. **(3분)** **화면으로 확인합니다.** 위 uvicorn 창은 **Ctrl+C 로 끄고**:
   ```
   python ../화면/화면.py
   ```
   → 브라우저가 저절로 열립니다(`http://127.0.0.1:8000/`). 위쪽 **확인 목록 다섯 칸**이 TODO 1~4와 짝입니다 —
   빨간 칸이 남아 있으면 그 TODO로 돌아가십시오. 「새 기수형 훈련생★」을 누르고 **응답한 모델이 v2인지** 봅니다.
   (TODO를 하는 중간에 띄워 봐도 됩니다. 끄기: 그 창에서 Ctrl+C)

## 왜 여섯 항목을 다 받나

지금 걸린 v2는 여섯 개를 다 씁니다. 그런데 **다음 주에 v1으로 되돌릴 수도** 있습니다(lab6).
그때 입력 항목이 둘로 줄어든다면, 이 API를 부르는 모든 곳을 같이 고쳐야 합니다.

**호출하는 쪽(교재: 부르는 쪽)은 안쪽 사정을 몰라도 되어야 합니다.** 그것이 「약속」이라는 말의 뜻입니다.

## 막혔을 때

| 증상 | 이렇게 |
|---|---|
| `준비.py` 에서 `RESOURCE_DOES_NOT_EXIST` | `mlflow.db` 는 **돌린 폴더**에 생깁니다. 같은 폴더에서 돌리십시오 |
| C7이 500이다 | 막은 것이 아니라 **터진** 것입니다. 받는 모양을 못 박으십시오 |
| C8이 200이다 | 범위 조건이 없습니다. `Field(ge=0, le=1)` |
| C9가 계속 실패 | 소스에 `models:/이름/숫자` 가 남아 있습니다 |
| 특성 목록을 어디서 가져오나 | 버전 태그입니다. `mv.tags["features"]` |
| 포트가 이미 쓰인다 | `--port 8001` 로 바꾸십시오. 검증 스크립트는 포트를 쓰지 않습니다 |

## 대체 경로 (설치가 막힐 때)

`fastapi` 가 안 깔리면 **표준 라이브러리 `http.server`** 로 같은 세 문을 냅니다.
계약 내용은 그대로입니다. 검증은 강사 화면에서 함께 봅니다.
